# Internship Eligibility Form Automation using n8n

## Overview

This project automates the internship eligibility verification process using n8n.

## Features

- Internship Application Form
- Edit Fields
- IF Condition
- Gmail Integration
- Google Sheets Integration
- Automatic Eligibility Check

## Workflow

On Form Submission
↓
Edit Fields
↓
IF
├── Eligible → Gmail → Google Sheets
└── Not Eligible → Gmail → Google Sheets

## Technologies

- n8n
- Gmail
- Google Sheets
- Workflow Automation

## Eligibility Criteria

- CGPA ≥ 7.5
- Attendance ≥ 75%
- Backlogs = 0

## Installation

1. Install n8n.
2. Import `internship-eligibility-workflow.json`.
3. Configure Gmail credentials.
4. Configure Google Sheets credentials.
5. Activate the workflow.
